# Arabic Leadership Recruitment SaaS — MVP

نسخة تشغيلية أولى للواجهة ودورة الاستخدام. الاسم التجاري مؤقت إلى حين إنهاء فحص العلامة.

## التشغيل
```bash
npm install
npm run dev
```
ثم افتح `http://localhost:3000`.

## المسارات
- `/` صفحة المنتج
- `/dashboard` لوحة القائد
- `/candidates` CRM
- `/candidates/1` ملف مرشح
- `/f/demo` القمع العام
- `/f/demo/apply` بيانات المرشح
- `/f/demo/assessment` التقييم
- `/f/demo/result` النتيجة
- `/f/demo/booking` طلب المقابلة

## الحالة الحالية
هذه نسخة MVP تجريبية. إعدادات Supabase موجودة ضمن المشروع لاستكمال الربط والاختبار.
